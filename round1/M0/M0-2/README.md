# M0-2 相关系数计算工具

## 一、如何运行

### 1. 环境要求
- Python 3.10+
- 依赖：`PyYAML`

### 2. 安装依赖
```bash
pip3 install pyyaml
```

### 3. 运行命令
```bash
python3 corr.py --config config.yaml
```
**参数说明**：
- `--config`：指定 YAML 配置文件路径。

### 4. 运行示例
```bash
$ python3 corr.py --config config.yaml
n = 40
mean_x = 49.43782499999999
mean_y = 43.310725
r = 0.5634747252452482
```

---

## 二、输入文件格式要求

程序采用 YAML 文件作为配置，通过 CSV 文件提供数据。

### 1. YAML 配置文件（config.yaml）
```yaml
input_csv: sample_data.csv
columns:
  x: sensor_a
  y: sensor_b
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `input_csv` | 字符串 | CSV 数据文件路径。支持绝对路径和相对路径。**若为相对路径，程序会自动以 `config.yaml` 所在目录为基准进行解析**，保证在不同目录下运行均能找到文件。 |
| `columns.x` | 字符串 | 参与计算的 x 列列名，必须与 CSV 表头一致。 |
| `columns.y` | 字符串 | 参与计算的 y 列列名，必须与 CSV 表头一致。 |

### 2. CSV 数据文件
- 第一行为表头，必须包含 `columns.x` 和 `columns.y` 指定的列名。
- 这两列的值必须是**数值类型**（整数或浮点数）。
- 其他列可以存在，但不会被使用。

示例（sample_data.csv）：
```csv
timestamp,sensor_a,sensor_b,note
1,10,20,a
2,20,40,b
3,30,60,c
```

## 三、输出结果的含义

程序向标准输出（stdout）打印四行结果：

```text
n = 40
mean_x = 49.43782499999999
mean_y = 43.310725
r = 0.5634747252452482
```

| 字段 | 含义 | 取值范围 |
|------|------|----------|
| `n` | 参与计算的样本数量（数据行数） | 正整数 |
| `mean_x` | x 列数据的算术平均值 | 实数 |
| `mean_y` | y 列数据的算术平均值 | 实数 |
| `r` | 皮尔逊相关系数 | **[-1, 1]** |

### 相关系数 r 的解读
- `r = 1`：完全正相关，x 增大时 y 同比例增大。
- `r = -1`：完全负相关，x 增大时 y 同比例减小。
- `r = 0`：无线性相关。
- `|r|` 越接近 1，线性相关性越强。

## 四、设计权衡与防错机制

1. **配置读取的防御性编程**：`yaml.safe_load` 解析出来的根节点不一定是字典（可能是列表）。为了防止后续使用 `cfg["input_csv"]` 时发生 `TypeError` 裸崩，代码中加入了 `if not isinstance(cfg, dict)` 判断，提前给出友好的格式错误提示。
2. **路径解析**：使用了 `pathlib` 库。当 CSV 路径为相对路径时，通过 `resolve().parent` 获取配置文件所在目录，从而拼接出绝对路径，避免因终端工作目录不同导致文件找不到。
3. **异常拦截**：在 `main` 函数的最后，通过 `except Exception as e` 捕获所有未处理的异常，通过 `sys.stderr` 输出可读错误并 `sys.exit(1)`，确保程序在输入异常时优雅退出，不暴露底层 Traceback。

运行自动化测试脚本验证核心算法与边界条件：
```bash

```
