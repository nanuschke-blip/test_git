# M0-2 相关系数计算工具

## 一、如何运行

### 环境要求
- Python 3.10+
- 依赖：`PyYAML`

安装依赖：
```bash
pip3 install pyyaml
```

### 运行命令
```bash
python3 corr.py --config config.yaml
```

参数说明：
- `--config`：指定 YAML 配置文件路径（必填）

### 运行示例
```bash
$ python3 corr.py --config config.yaml
n = 40
mean_x = 49.43782499999999
mean_y = 43.310725
r = 0.5634747252452482
```

## 二、输入文件格式要求

### 1. YAML 配置文件（config.yaml）

```yaml
input_csv: sample_data.csv
columns:
  x: sensor_a
  y: sensor_b
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `input_csv` | 字符串 | CSV 数据文件路径。支持绝对路径和相对路径，相对路径以 config.yaml 所在目录为基准解析 |
| `columns.x` | 字符串 | 参与计算的 x 列列名，必须与 CSV 表头一致 |
| `columns.y` | 字符串 | 参与计算的 y 列列名，必须与 CSV 表头一致 |

### 2. CSV 数据文件

- 第一行为表头，必须包含 `columns.x` 和 `columns.y` 指定的列名。
- 这两列的值必须是数值类型（整数或浮点数）。
- 其他列可以存在，但不会被使用。

示例（sample_data.csv）：
```
timestamp,sensor_a,sensor_b,note
1,10,20,a
2,20,40,b
3,30,60,c
```

## 三、输出结果的含义

程序向 stdout 打印四行结果：

```
n = 40
mean_x = 49.43782499999999
mean_y = 43.310725
r = 0.5634747252452482
```

| 字段 | 含义 | 取值范围 |
|------|------|----------|
| `n` | 参与计算的样本数量 | 正整数 |
| `mean_x` | x 列数据的算术平均值 | 实数 |
| `mean_y` | y 列数据的算术平均值 | 实数 |
| `r` | 皮尔逊相关系数 | [-1, 1] |

### 相关系数 r 的解读
- `r = 1`：完全正相关，x 增大时 y 同比例增大。
- `r = -1`：完全负相关，x 增大时 y 同比例减小。
- `r = 0`：无线性相关。
- `|r|` 越接近 1，线性相关性越强。

## 四、异常处理

程序对以下情况会打印可读的错误信息并以非 0 退出码结束，不会抛出 Python Traceback：

| 异常情况 | 错误提示 |
|----------|----------|
| 配置文件不存在 | `错误: 配置文件不存在: xxx` |
| YAML 格式错误 | `错误: YAML 解析失败: xxx` |
| CSV 文件不存在 | `错误: CSV 文件不存在: xxx` |
| CSV 缺少指定列 | `错误: CSV 中缺少列: xxx` |
| CSV 存在非数值数据 | `错误: CSV 中存在非数值数据: xxx` |
| 数据为空 | `错误: 数据为空，无法计算相关系数` |
| 两列长度不一致 | `错误: x 和 y 的长度不一致` |
| 方差为 0 | `错误: 方差为 0，相关系数无定义` |
