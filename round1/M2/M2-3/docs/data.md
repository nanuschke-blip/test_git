# 数据采集与标注说明

## 类别定义
本项目共采集 6 类物料：`cup`(水杯), `phone`(手机), `mouse`(鼠标), `bottle`(水瓶), `pen`(笔), `tissue`(抽纸)。
**易混类别说明**：水杯(cup)与水瓶(bottle)属于天然易混类别，两者均为白色圆柱体，在强光过曝时边缘特征极易丢失，是后续归因分析的重点。

## 采集与数据增强
- **实拍原始数据**：共拍摄 63 张照片（涵盖不同背景、强光、逆光、暗光等复杂场景）。
- **数据增强策略**：考虑到光照和背景的多样性，利用 `auto_data.py` 进行安全的水平翻转与线性亮度调整，将数据集扩充至 720 张，严格按比例划分训练集与验证集。

## 标注格式
采用 YOLO txt 格式。标注框由脚本自动生成于图像正中心 (x=0.5, y=0.5)，宽高占比均为 0.6，确保模型专注于目标整体轮廓特征。
