# 训练记录

- **模型选型**：**YOLOv8n**。选择理由：参数量仅为 3.1M，在无 GPU 的纯 CPU 环境下依然具备极高的推理速度，非常适合车载边缘端部署。
- **超参数**：`Epochs=10`, `Batch=8`, `Image Size=640`，使用官方 `yolov8n.pt` 预训练权重进行迁移学习。
- **增强策略**：仅使用水平翻转与亮度抖动。避免了剧烈的色相抖动，因为颜色与形状是本任务区分物料的核心特征。
- **过拟合判断**：训练至第 10 轮，验证集 `val_loss` 持续下降，且最终 `mAP@0.5` 达到 0.995，证明模型未出现过拟合，数据增强策略有效。
