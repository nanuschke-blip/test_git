## 1. 重点（考官会盯的 4 件事）

1. **内参来自 M2-1**（同一台相机），不是重新标或写死；
2. **IPPE 的镜像歧义**及"用重投影误差选解"；
3. **深度精度随距离下降**的物理原因；
4. **畸变对近距的影响**（0.31 vs 0.28 m）。

## 2. 知识点

### 2.1 为什么 4 个点能解 6-DoF

平面靶标所有点 `Z_w = 0`。每个 2D-3D 点对给 2 个方程；4 点 → 8 个方程，
未知数 6（R 3 + t 3）→ 超定 2 个方程，可解且可用于校验。实际用全部 54 个内角点，冗余更大。

### 2.2 PnP 求解器对比

| 方法 | 特点 | 适用 |
|---|---|---|
| `SOLVEPNP_ITERATIVE` | LM 迭代，需要初值 | 通用 |
| `SOLVEPNP_EPnP` | O(n) 闭式，通用 | 点数多、非平面 |
| **`SOLVEPNP_IPPE`** | 专为**平面**设计，解析解、无初值、快，但**返回两个解** | 本题（棋盘格/ArUco） |
| `SOLVEPNP_SQPNP` | 全局最优，较新 | 通用 |

### 2.3 镜像歧义（planar ambiguity）

平面目标的投影对"翻面"不敏感：`(R, t)` 与 `(R', t')` 可能给出几乎相同的重投影。
IPPE 直接给出两解，选 `reprojection error` 小的即可；点数越多、姿态越斜，区分度越高。
正面正对（接近 0°）时两解几乎重合，误差差很小——这也是"正对时抖动"的原因。

### 2.4 欧拉角

`cv2.Rodrigues(rvec)` 得 R，再按 **XYZ 内旋**分解：

```
pitch = asin(-R[2,0])                    # 绕 X
yaw   = atan2(R[2,1], R[2,2])            # 绕 Y
roll  = atan2(R[1,0], R[0,0])            # 绕 Z
```

（内旋与外旋、XYZ 与 ZYX 顺序不同会导致角度符号/数值不同，报告里要写明用的是哪一种。）

### 2.5 深度误差为什么随距离放大

一个像素的角点误差 δu 对应深度方向误差近似：

```
δZ ≈ Z² · δu / (f · b_eff)      # b_eff 为靶标在像面上的等效基线
```

`Z²` 决定它增长得快：0.5 m 时可能 1 cm 级，1.2 m 时可能 5 cm 级。所以"越远越不准"是几何必然。

### 2.6 畸变的影响

`solvePnP` 里的 `distCoeffs` 先把像点去畸变；不传时角点仍带桶形偏移，
近距离时同样的像素偏移对应更大的角度误差，所以**近距离最差**（实测 0.31 → 0.28 m，约 −10%）。

## 3. 算法逻辑

```
frame → gray → findChessboardCorners(9x6) → cornerSubPix(11x11, 30 iter, 1e-3)
      → objp = mgrid(9,6) * square_size（z=0）
      → solvePnPGeneric(IPPE, K, dist) → 两解 + 各自重投影误差
      → 取重投影误差小的解 → Rodrigues → RPY
      → drawFrameAxes(axis_len = 0.5×square_size)
      → 叠显 [Dist, Yaw, Pitch]
```

## 5. 经验总结

1. **靶标必须贴平硬纸板**：纸一翘，平面假设失效，Z 会系统性偏。
2. **角点亚像素是精度的关键**：`cornerSubPix` 前后重投影误差能差一个量级。
3. **边长要实测**：24.0 mm 不是 25 mm；写错所有距离等比错。
4. **正对时两解难分**：姿态接近 0° 时镜像解误差几乎相同，角度会跳，演示时给个明显倾斜的姿态。
5. **畸变必须传**：不传时近距 Z 偏 10%，这是"为什么要复用 M2-1 内参"的最强证据。

## 6. 答辩对策

**Q1：为什么用 IPPE 不用 ITERATIVE/EPnP？**
A：靶标绝对平面，IPPE 是平面专用的解析解，无初值、快；ITERATIVE 要初值且可能收敛到镜像解；
EPnP 通用但不利用平面约束。代价是 IPPE 给两解，需要按重投影误差选。

**Q2：两个解怎么选？会不会选错？**
A：`solvePnPGeneric` 同时返回两解的 `reprojErrs`，取小的。姿态越斜区分度越高；
正对时两解几乎重合，此时角度误差本身也小，实际影响不大。

**Q3：怎么证明四角点顺序对？**
A：把棋盘格顺时针转 90°，观察画出的起始角点（左上 TL）是否跟着靶标自身左上角走，
而不是固定在图像某个像素位置。

**Q4：为什么距离越远越不准？**
A：深度误差 ∝ Z²δu/(f·b)；像素误差 δu 不变，Z 越大放大越快。0.3 m 误差 1 cm 级，
1.2 m 可能 5 cm 级。要更准只能增大靶标/提高分辨率/多帧平均。

**Q5：为什么不带畸变近距离最差？**
A：近距时桶形畸变让角点像素偏移最大（离主点远 + 透视强），同样的畸变残差换算成角度误差更大；
远距时靶标在像面占的像素少、畸变影响相对小。

**Q6：欧拉角顺序是什么？会不会有万向锁？**
A：XYZ 内旋（pitch/yaw/roll 按 R 矩阵元素反解）。万向锁出现在 pitch=±90°，
正常使用（±60° 内）没问题；要彻底避免就输出四元数或旋转矩阵。

**Q7：现场让我把边长改成 80 mm 怎么办？**
A：`python3 pose_estimate.py -i ... -c camera_calibration.yaml --square-size 80`，
距离会变成 80/24 ≈ 3.33 倍——因为物体系单位变了，这是正确行为（同一张图，靶标"更大"则更近）。

**Q8：精度表里为什么没有 1.2 m 和 30/60/90°？**
A：只做到 0.3/0.5/0.8 三档与 3 个自由姿态；现场可以补测 1.2 m（卷尺 + 三次取均值），
但我不会编没测过的数字。
